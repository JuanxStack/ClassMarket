# Classmarket

Sistema web completo de marketplace/catálogo desenvolvido com front-end em HTML, CSS e JavaScript, back-end em Node.js/Express e banco de dados relacional SQL.

## Funcionalidades
- Cadastro e autenticação de usuários (com criptografia de senha via `bcrypt`)
- Catálogo e visualização detalhada de produtos
- Cadastro de novos produtos e painel administrativo
- Sistema de avaliações

## Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end:** Node.js, Express
- **Banco de Dados:** SQL (`database/classmarket.sql`)
